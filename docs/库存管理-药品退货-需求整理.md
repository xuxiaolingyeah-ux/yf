# 库存管理 · 药品退货模块 · 需求整理

> 版本：v1.0（口径已确认，待出线稿）　日期：2026-11-11
> 来源：口述需求整理；参考现有「药品出库」「药品退库」及采购管理模式，基于区域药房协同管理系统 demo 升级改造

## 〇、已确认结论（2026-11-11）

1. **与「药品退库」是两个流程，分开**：药品退货 = 将药品**退给供应商**；药品退库（stock-return*）= 返回给其他机构。两者并存、互不影响。
2. **菜单位置**：一级目录「库存管理」下、「药品出库」之后，新增二级菜单「药品退货」。
3. **单号口径**：单号 = 退货单号，前缀 **TH**；「出库时间」列/筛选口径 = **退货申请提交时间**（沿用原字段名展示）。
4. **发票号**：表头（选填）与明细均展示；**明细行默认展示入库时录入的发票号**。
5. **关联入库单**：仅限**已审核通过**的入库单，**支持关联多个**。
6. **追溯码**：参考出库页录入方式（扫码/手工），但**不强制**追溯码数量与退货量相等，无强制校验要求。
7. **审核链路**：所有机构提交后均由**上一级机构审核**；中心药房自身发起的退货**同样需上级审核**（※中心药房为系统最高层级，上级审核的具体落点待定）。
8. **可见角色**：三类药房人员（中心/成员/村室）可见，HIS 对接人员不可见。
9. **数据权限**：沿用「按发起机构向上汇总」口径——村室仅本村室；成员机构=本机构+下属村室；中心药房=全部。

> 遗留小项：审核拒绝时意见是否必填（沿用采购需求详情页「拒绝必填意见」模式即可，待出线稿时如有异议再调）。

## 二、退货列表（drug-return.html）

**标题栏**：页面标题 + 「**新增退货**」按钮（右侧）。

**筛选条件**：单号、出库时间（区间）、供应商、审核状态。

**列表列**：

| 列 | 说明 |
|---|---|
| 单号 | 退货单号（前缀 TH） |
| 出库时间 | 口径 = 退货申请提交时间（字段名沿用原需求） |
| 供应商 | — |
| 涉及药品笔数 | 明细行数 |
| 进货价金额合计 | Σ（退货量 × 进货价） |
| 零售价金额合计 | Σ（退货量 × 零售价） |
| 提交人 / 提交时间 | — |
| 审核状态 | 草稿 / 待审核 / 审核通过 / 已拒绝（与采购需求口径一致） |
| 操作 | 见下 |

**操作规则（状态 × 身份）**：
- **草稿 / 已拒绝**：查看、编辑、提交、删除
- **待审核**：审核人 → 查看、审核；提交人 → 查看、撤销
- **审核通过**：查看

## 三、新增退货（drug-return-create.html）

### 3.1 退货信息（表头）

| 字段 | 必填 | 控件 |
|---|---|---|
| 供应商 | 必填 | 下拉选择（供应商档案/本机构分配的供应商） |
| 发票号 | 选填 | 输入框 |
| 退货说明 | 选填 | 多行文本 |

### 3.2 药品明细

**添加方式**：
1. **单个添加** / **批量添加**（弹窗选药，参考采购需求批量添加模式）；
2. **关联入库单代入**：选择入库单后直接带入其药品明细（入库单号、批次等随之代入）；仅限已审核通过的入库单，**支持关联多个**。

**明细列**：

| 列 | 录入方式 |
|---|---|
| 药品名称 / 编码 / 规格 / 生产企业 | 代入，只读 |
| 批号 | 代入（按批次），只读 |
| 库存量 | 代入，**带单位** |
| 退货量 | **手工录入**，**带单位**（校验：退货量 ≤ 库存量，待确认） |
| 进货价 / 零售价 | 代入 |
| 进货价金额合计 | 自动计算 = 退货量 × 进货价 |
| 零售价金额合计 | 自动计算 = 退货量 × 零售价 |
| 批准文号 | 代入 |
| 发票号 | 默认展示**入库时录入的发票号** |

**追溯码**：参考药品出库（outbound-create）的追溯码抽屉——扫码/手工录入、格式校验（8 位以上数字）、与药品一致性校验、防重复；**不强制追溯码数量与退货量相等**，未录满也可提交审核（已确认 2026-11-11）。

### 3.3 提交后流程

提交 → **上一级机构审核**（村室→成员机构→中心药房；**中心药房发起同样需上级审核**）。审核通过/拒绝，拒绝意见建议必填（沿用采购需求详情页模式）。
