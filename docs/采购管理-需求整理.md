# 采购管理模块 · 需求整理

> 版本：v1.0（已确认）　日期：2026-11-09
> 来源：口述需求整理；基于现有 demo（区域药房协同管理系统）样式升级改造

## 〇、已确认结论

1. **审核链路**：村室发起 → 成员机构审核 → 中心药房终审；成员机构发起 → 中心药房审核；中心药房发起 → 无需审核（提交即生效）。
2. **旧页面处置**：现有 purchase-request*（采购申请）升级改造为「采购需求」，复用 purchase-common.js / styles.css。
3. **菜单可见角色**：村室 → 仅「采购需求」；成员机构 → 「采购需求 + 采购计划」；中心药房 → 三个菜单全部可见；HIS 对接人员不可见整个采购管理。
4. **线稿形式**：可交互 HTML 线稿，按现有 styles.css 组件风格实现。

在左侧导航新增**一级目录「采购管理」**（位于「库存管理」之上），下设三个二级菜单：

| 二级菜单 | 页面文件（建议） | 说明 |
|---|---|---|
| 采购需求 | purchase-need.html / -create.html / -detail.html | 需求申请与审核 |

- 业务流程（需求/计划）：**村室 / 成员机构 / 中心药房 发起 → 上级机构审核**
- 可见角色：村室、成员机构、中心药房（三类药房人员可见，HIS 对接人员不可见）※待确认

## 二、采购需求

### 2.1 发起采购申请（purchase-need-create.html）

**基本信息区**
| 字段 | 控件 | 说明 |
|---|---|---|
| 申请机构 | 只读输入框 | 当前登录机构，不可改 |
| 申请库位 | 下拉单选 | 该机构下库位 |
| 申请说明 | 多行文本 | 选填 |
| 提交人 / 提交时间 | 只读 | 默认登录人 / 当前时间 |

**药品明细区**
- 添加方式：单个添加 或 批量添加（弹窗选择药品）
- 批量添加筛选项：①「库存低于下限」条件筛选；② 药品种类筛选
- 明细列：药品名称、药品编码、药品规格、生产企业、**需求数量（用户录入）**、库存数量、库存上限、库存下限

### 2.2 采购申请列表（purchase-need.html）

| 列 | 说明 |
|---|---|
| 需求单号 | — |
| 涉及药品笔数 | 明细行数 |
| 提交人 | — |
| 提交时间 | — |
| 审核状态 | 草稿 / 待审核 / 审核通过 / 已拒绝 |
| 操作 | 见下 |

**操作规则（按状态 × 身份）**
- 已拒绝 / 草稿（发起人）：查看、编辑、提交、删除
- 待审核（发起人）：查看、撤回
- 待审核（审核人）：查看、审核
- 审核通过：查看

**筛选条件**：需求单号、审核状态、提交人、提交时间（区间）

## 三、采购计划

### 3.1 发起采购计划（purchase-plan-create.html）

**基本信息区**：与采购申请一致（申请机构只读、申请库位下拉、申请说明选填、提交人/提交时间默认登录人）。

**药品明细区**
- 明细列：药品名称、药品编码、药品规格、生产企业、**基药（是/否）**、**计划数量（用户录入）**、**单价（用户录入）**、**总价（系统计算 = 数量 × 单价）**
- 批量添加筛选项：药品种类、「库存低于下限」

**关联采购需求（核心特性）**
- 支持直接关联**已审批通过**的采购需求，可关联单个 / 多个
- 合并规则：**同一药品 + 同一规格 + 同一生产企业** → 计划数量自动累加
- 累加后计划数量仍支持用户手动修改

### 3.2 采购计划列表（purchase-plan.html）

| 列 | 说明 |
|---|---|
| 计划单号 | — |
| 涉及药品笔数 | 明细行数 |
| 合计金额 | Σ 总价 |
| 基药金额占比 | 基药总价 / 合计金额（%）※口径待确认 |
| 提交人 / 提交时间 | — |
| 审核状态 | 同采购需求 |
| 操作 | 同采购需求（查看/编辑/提交/删除/撤回/审核） |

**筛选条件**：计划单号、审核状态、提交人、提交时间（区间）

## 四、采购订单

### 4.1 订单列表（purchase-order.html）

数据来源：**同步省药品招采平台采购订单**（本 demo 用 mock 数据模拟）。

| 列 | 说明 |
|---|---|
| 省平台订单号 | — |
| 关联采购计划数 | 可点击 → 查看关联计划详情 |
| 订单发起时间 | — |
| 订单状态 | ※待确认状态枚举 |
| 操作 | 关联采购计划 |

**筛选**：订单号（模糊查询）

### 4.2 关联采购计划详情

点击列表「关联采购计划数」→ 查看已关联的采购计划，字段：计划单号、合计金额、提交人、提交时间。

### 4.3 关联采购计划（弹窗）

点击操作列「关联采购计划」→ 弹窗内可**单个 / 批量添加或移除**当前已审核通过的采购计划；弹窗内支持筛选：**提交人、提交时间、关联状态（已关联/未关联）**，筛选切换过程中勾选状态保留，点「确定」统一提交。

## 六、原待确认问题（已于 2026-11-09 确认，结论见「〇」）

1. 审核链路 → 村室→成员→中心；成员发起由中心审；中心发起免审。
2. 旧页面处置 → 升级改造为采购需求。
3. 菜单可见角色 → 村室仅需求；成员需求+计划；中心全可见。
4. 订单状态枚举：线稿先按「已同步 / 部分入库 / 已完成」模拟，正式需求再确认。
5. 药品种类筛选：按现有药品字典分类（西药 / 中成药 / 中药饮片 / 疫苗 / 配方颗粒）。
6. 线稿形式 → 可交互 HTML 线稿。
