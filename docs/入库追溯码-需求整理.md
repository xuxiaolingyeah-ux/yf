# 入库追溯码采集 · 需求整理

> 版本：v1.0（已确认）　日期：2026-11-12
> 来源：口述需求整理；多轮线稿评审定稿（wireframe-stock-in-trace.html v4）
> 范围：本期仅做**手工录入**（不做 Excel 导入）；涉及 stock-in-create.html / stock-in-detail.html / stock-in-common.js

## 〇、已确认结论

1. **页面信息不变**：新增/编辑入库页面的入库信息、发票信息、药品明细各列、其余校验逻辑全部保持现状，唯一改动是「录入追溯码」的承载方式：居中弹窗 → **右侧抽屉**。
2. **不做数量强制校验**：想录几个追溯码都可以，明细「追溯码进度」列沿用原展示样式（已录条数 / 合格数量），仅展示、不拦截提交。
3. **大/中包装码整码入列**：选择大包装/中包装后扫的码**整条入列表**（1 码 = 整箱/整中包），只记录原码，扫码阶段**不调接口**。
4. **延迟解析**：点抽屉「确定」后，才调级联映射接口把大/中包装码批量解析成小包装码；解析结果随单据落库，作为后续出库/上传医保的依据（上传单元必须是**小包装码**）。
5. **查看追溯码为全层级展示**：查看抽屉按 大包装 / 中包装 / 小包装 **分组**展示，组内不再重复「包装类型」标签；已解析的大/中码可展开查看拆出的小码。
6. **抽屉内可切换药品**：录入/查看抽屉打开时，点击其他药品明细行（或行内按钮）直接切换抽屉内容，当前行高亮；两抽屉互斥，切换前若有未确定修改需确认。
7. **抽屉内列表列固定**：追溯码、类型（小包装/中包装/大包装）、操作（删除）。不做：使用次数、批量添加、批量修改次数、Excel 导入、「已录入未入库追溯码」Tab（后者留待「追溯码管理/上传医保」模块用 uploadStatus 做）。

## 一、录入追溯码抽屉（stock-in-create.html）

自上而下：

| 区域 | 内容 |
|---|---|
| 抽屉头 | 标题「录入追溯码」+ 关闭 |
| 药品信息 | 药品名称、规格、生产企业（只读，取自当前明细行） |
| 追溯码类型 | 紧凑切换：小包装（默认）/ 中包装 / 大包装 |
| 录入操作 | 紧凑切换：**添加扫码**（默认）/ **移除扫码**；均支持扫码枪或手输，回车确认 |
| 码列表 | 列：追溯码、类型、操作（删除）；已解析的码附注「已拆出 N 个小码」，解析失败的箱码标红提示 |
| 底部 | 统计（已录入条数 / 已解析小码数）+ 取消 / 确定 |

**交互规则**
- 添加模式：码重复拦截（"该追溯码已录入，请勿重复"）。
- 移除模式：命中列表即删；移除大/中包装码时**连带清除**其解析出的小码；未命中提示"未找到该追溯码，无法移除"。
- 点「确定」：保存本行码清单；若有未解析的大/中码，调接口解析（带进度），完成后更新明细行追溯码进度，解析失败的箱码保留原码并标记失败（**不阻断保存**）。
- 解析失败的兜底：提示"平台无级联关系，请改扫小码"，操作员改扫小包装码录入。

## 二、查看追溯码抽屉（stock-in-detail.html / 明细行入口）

- 右侧抽屉；顶部药品名称、规格、生产企业。
- 按大包装 → 中包装 → 小包装分组；每组标题带数量（如「大包装（2 个）」）。
- 已解析的大/中码：显示"已拆出 N 个小码"+ 展开/收起（小码列表）。
- 无码显示空态"该药品暂未录入追溯码"。底部统计各层级数量与已解析小码数。

## 三、数据模型

```
item.traces[]          : [{ code, level }]   level: small | mid | large（旧数据无 level 视为 small）
item.traceResolved{}   : { [大/中码]: [小码...] }   解析结果随单据落库
码字段                  : varchar(100)，GS1 码 42–86 位、含字母，不得按纯数字/定长校验
```

## 四、政策与对接背景（实现注意）

- 2026-01-01 起全量采集上传（含非定点机构），2026-07 起医保局+药监局联合检查；入库验收需与上游追溯信息比对。
- 级联映射（大→中→小）库由国家医保局免费开放；厂商主流做法（ABC、掌店易、千方百剂）均为「扫大码、提交时解析小码、自动上传」，与本方案一致。
- 上传医保的单元必须是**最小销售包装（小码）**；中药饮片、配方颗粒、院内制剂、必须拆零发放的药品暂不强制采集（后续按药品类型控制必录时再扩展）。
- 演示约定：以 `7777` 结尾的箱码模拟"平台无级联关系"解析失败；大码拆 20 小码、中码拆 10 小码。
